# Runtime Module Re-Exports

## Summary

`mod.rs` exposes the runtime helper modules used by generated Rust simulators.

## Exposed Interfaces

- `cast`: integer and bit-vector conversion helpers.
- `coverage`: optional source-level semantic coverage recording.
- `utils`: logging and formatting helpers.
- `xeq`: cycle-indexed queues, FIFOs, and register-array support.

## Internal Helpers

This module has no internal helpers.
