# 0to100 Source Sidecar

`0to100.c` is the source-level sidecar for the converted Assassyn
`0to100.{exe,data,config}` workload.

## Interface

- `main()` sums the 100 fixture data words and returns `630665` when the data
  matches the converted RV32 image.
- `setStats(1)` and `setStats(0)` bracket the summation loop so x86
  source-level runs expose an ROI window.

## Data Structures

- `zero_to_hundred_data` is a volatile stack array populated before the ROI
  with explicit scalar stores. This avoids dependence on flat-image `.rodata`
  loading while still mirroring the 100 unsigned words in `0to100.data`.
- `expected` is a volatile checksum guard. The explicit branch keeps the
  constrained x86 output inside LLPM's currently supported frontend subset.
- `ZERO_TO_HUNDRED_COUNT` and `ZERO_TO_HUNDRED_EXPECTED` define the fixture
  length and expected checksum used by the dual-ISA source compiler guards.

## Internal Helpers

The file intentionally has no helper functions. Keeping the loop body in
`main()` makes the generated x86 ROI easy to inspect in disassembly and keeps
the source tied directly to the existing data fixture.
